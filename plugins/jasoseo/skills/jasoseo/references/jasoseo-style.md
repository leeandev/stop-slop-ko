# 자소서 문체 규칙

stop-slop-ko 플러그인이 없어도 이 파일만으로 적용한다. stop-slop-ko의 개조식(`~함/~됨`) 기본값은 자소서에 쓰지 않는다.

## 종결

- 기본은 `~습니다/~했습니다`. 사용자가 다른 종결(`~다`)로 쓴 본문을 주면 그것을 따른다.
- 한 글 안에서 종결을 섞지 않는다.
- 개조식과 명사 종결은 쓰지 않는다.

## 자소서 AI 티 패턴

| 패턴 | 예 | 고치는 방향 |
|---|---|---|
| 교훈형 마무리 | 이러한 경험을 통해 소통의 중요성을 배웠습니다 | 그 뒤 실제로 바뀐 행동 하나 |
| "~라고 생각합니다" 남발 | 한 글에 두 번 이상 | 사실이나 행동으로 말한다 |
| 회사 비전을 그대로 옮긴 포부 | 귀사의 글로벌 비전 실현에 기여하는 인재가 되겠습니다 | 첫해 맡을 일과 거기 쓸 경험 |
| 형용사 세 개 나열 | 성실하고 꼼꼼하며 책임감 있는 | 하나를 골라 장면으로 보인다 |
| 대구와 과장 | 단순한 과제가 아닌 도전이었습니다, 잊지 못할, 소중한 | 사실만 남긴다 |
| 문항 되풀이로 시작 | 제가 귀사에 지원한 동기는 ~입니다 | 장면이나 사실로 시작한다 |
| 명언, 사자성어로 시작 | "실패는 성공의 어머니"라는 말처럼 | 지운다 |
| 연결어 연달아 쓰기 | 또한, 더불어, 나아가, 이를 바탕으로 | 꼭 필요한 곳 하나만 |
| 번역투 | ~을 통하여, ~에 있어서, ~되어지다, ~로 인하여 | ~로, ~에서, ~되다, ~ 때문에 |
| 빈 강조어 | 정말, 매우, 굉장히, 진정한 | 지운다 |

## 부호

- em-dash(`—`), 장식 이모지, `★`를 쓰지 않는다.
- 따옴표는 사용자 말이나 실제 대사를 옮길 때만 쓴다.
- 조사 앞에 공백을 두지 않는다(`React와`).

## 판단 기준

고친 문장이 카드의 원문 인용과 같은 사람이 쓴 것처럼 읽히는지 본다. 더 매끄러워졌어도 사용자 말투가 사라졌으면 원래 표현으로 되돌린다.
