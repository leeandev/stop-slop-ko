# jasoseo 플러그인 설계

작성일: 2026-10-10
상태: 설계 승인, 구현 계획 전

## 목적

취업 자기소개서(자소서)를 Claude가 대신 지어 쓰지 않고, 인터뷰로 지원자 본인의 경험을 끌어내 본인 말투로 초안을 만드는 Claude Code 플러그인. stop-slop-ko 마켓플레이스에 세 번째 플러그인으로 넣는다.

- 대상: 한국 기업 자소서를 쓰는 취업 준비생, 이직 준비자
- 성공 기준
  - 초안의 모든 사실 문장이 경험 카드에 근거가 있다. 근거 없는 사실은 `[확인 필요: ...]`로 남는다.
  - 문항 글자 수 제한을 `count.py`로 확인해 제한의 90~100% 안에 맞춘다.
  - 경험 은행에 쌓인 카드를 다음 회사 자소서에서 다시 쓸 수 있다.
  - stop-slop-ko를 설치하지 않아도 단독으로 동작한다.

## 범위 밖

- AI 탐지기 회피. 요청이 와도 스킬 목적이 아니라고 밝힌다.
- 대학 과제·리포트, 이력서, 경력기술서
- 영문 cover letter
- 초안 문장과 카드를 기계로 맞추는 근거 검사 스크립트(근거 점검은 Claude가 draft-rules에 따라 한다)

## 결정 사항

| 항목 | 결정 |
|---|---|
| 이름 | `jasoseo` (호출 `/jasoseo`, 플러그인 ID `jasoseo@stop-slop-ko`) |
| 범위 | 자소서 전용 |
| 초안 작성 | Claude가 인터뷰 답변만으로 초안을 쓴다. 답에 없는 경험·수치는 만들지 않는다 |
| 경험 저장 | 경험 은행 md 파일에 카드로 쌓아 재사용 |
| 구성 | 스킬 하나 + references + 글자 수 스크립트(안 A) |
| stop-slop-ko 관계 | 의존하지 않는다. 자소서 전용 문체 규칙을 자체 포함한다 |

stop-slop-ko에 기대지 않는 이유: 설치하지 않은 사용자가 있고, stop-slop-ko 규칙은 개조식 실무문서 기준이라 자소서 특유의 AI 티(교훈형 마무리, "~라고 생각합니다" 남발, 거창한 포부, `[소제목]` 두괄식 틀, 형용사 세 개 나열)를 잡지 못한다.

## 사용 흐름

1. 입력: 회사, 직무, 문항 원문, 글자 수 제한. 채용공고를 주면 직무 키워드를 뽑는다.
2. 문항 분석: 유형(지원동기, 성장과정, 직무역량, 갈등·실패, 입사 후 포부, 기타)과 문항이 실제로 묻는 것을 한 줄로 보여 준다.
3. 경험 은행 조회: 맞는 카드 후보 2~3개를 제시하고 사용자가 고른다. 없거나 얇으면 4로 간다.
4. 인터뷰: 한 번에 질문 1~2개. 시기, 내 역할, 숫자, 어려웠던 점, 내가 한 선택, 결과, 다시 한다면 바꿀 것. 답이 추상적이면 "예를 들면?"으로 되묻는다. 사용자 발화는 원문 그대로 남긴다.
5. 카드 저장: 경험 은행에 카드를 추가하거나 갱신한다.
6. 초안: 카드의 사실과 사용자 표현만 쓴다. 빈 곳은 `[확인 필요: ...]`. `count.py`로 글자 수를 재 제한의 90~100%에 맞춘다.
7. 점검 리포트: 근거가 카드에 없는 문장, 누구나 쓸 수 있는 뻔한 문장, 문체 규칙 위반, 글자 수. 사용자가 고친 본문을 주면 다시 점검한다.

## 경험 은행

- 위치: 현재 작업 폴더의 `jasoseo/stories.md`. 초안은 `jasoseo/<회사>-<직무>/<문항번호>.md`.
- 카드 ID는 `S01`부터 순번. 같은 경험은 새 카드를 만들지 않고 기존 카드를 갱신한다.

카드 양식:

```markdown
## [S03] 졸업작품 서버 장애 대응
- 시기·상황: 2025.03~06, 4인 팀 졸업작품, 시연 2주 전 서버 다운
- 내 역할: 백엔드 담당
- 한 일: 로그 분석 → DB 커넥션 누수 발견 → 풀 설정 수정
- 결과(숫자): 응답 3초 → 0.4초, 시연 정상 진행
- 어려웠던 점·선택: 기능 추가 vs 안정화 중 안정화를 주장
- 배운 점(본인 말): "고치는 것보다 원인 찾는 게 오래 걸린다는 걸 알았다"
- 쓸 만한 문항: 직무역량, 갈등·실패
- 원문 인용: "새벽 3시에 로그 보다가 커넥션이 안 닫히는 걸 봤어요"
- 사용 이력: A사 백엔드 2번 문항 (2026-10)
```

## 파일 구성

```
plugins/jasoseo/
  .claude-plugin/plugin.json
  skills/jasoseo/
    SKILL.md                     흐름, 핵심 원칙, 거절 상황
    references/question-bank.md  문항 유형별 질문 세트와 되묻기 요령
    references/story-card.md     카드 양식, 경험 은행 관리 규칙
    references/draft-rules.md    사실·말투 규칙, 점검 리포트 양식
    references/jasoseo-style.md  자소서 문체 규칙과 AI 티 패턴
    scripts/count.py             글자 수 계산
tests/test_count.py
```

함께 바꾸는 곳:

- `.claude-plugin/marketplace.json`: jasoseo 항목 추가, 버전 1.0.2 → 1.1.0
- `README.md`: jasoseo 소개 절과 Before/After
- 허브 `D:\dev\code\CLAUDE.md` 프로젝트 표의 stop-slop-ko 설명

`jasoseo-style.md`는 이후 stop-slop-ko 에세이·자소서 문체 모드(별도 작업)의 재료로 재사용한다.

## count.py

- Python 표준 라이브러리만 사용
- 입력: 파일 경로 또는 stdin
- 출력: 공백 포함, 공백 제외, 줄바꿈 포함·제외, UTF-8 바이트, EUC-KR식 바이트(한글 2바이트)
- `--limit N`: 기준값 대비 남은 글자 수와 초과 여부
- 기준값은 공백 포함(줄바꿈 포함). 사이트마다 세는 방식이 다르다는 안내를 출력에 함께 낸다
- EUC-KR로 인코딩되지 않는 문자(이모지 등)는 2바이트로 세고 경고한다

## 예외 상황

| 상황 | 동작 |
|---|---|
| 쓸 경험이 없다고 함 | 수업, 아르바이트, 동아리로 질문을 넓힌다. 그래도 없으면 쓸 거리가 부족하다고 알리고 지어내지 않는다 |
| "알아서 지어내 줘" | 거절하고 `[확인 필요]`로 남긴다. 자소서 내용은 면접에서 검증된다는 이유를 든다 |
| AI 검사기 회피 요청 | 스킬 목적이 아니라고 밝히고, 본인 경험과 말투가 가장 자연스럽다고 안내한다 |
| 개인정보 | 경험 은행은 로컬 파일. 주민번호, 연락처는 넣지 말라고 안내한다 |
